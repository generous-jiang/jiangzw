# 跨项目汇报

本目录存放横跨多个项目的汇报材料。单项目专属汇报放在各项目的 `04-reports/`。

## 目录约定

| 目录 | 频率 | 命名 | 受众 |
|---|---|---|---|
| [weekly/](weekly/) | 每周一次 | `YYYY-W{周数}.md` | 团队 + 直接老板 |
| [monthly/](monthly/) | 每月一次 | `YYYY-MM.md` | 业务部门负责人 |
| [quarterly/](quarterly/) | 每季一次 | `YYYY-Q{季度}-{主题}.md` | CEO + 业务总监 |

## 模板

- 周报：`templates/weekly-update.md`
- 月报/季度：`templates/biz-report-slidev.md`

## 给 Kiro 的常用指令

> "汇总各项目 meta.yaml 的最近更新和 git log，生成 `reports/weekly/2026-W22.md`"
> "把 wms-platform 和 erp-master-data 本月进展合并成给 CEO 的月度汇报，Slidev 格式，5 页内"
