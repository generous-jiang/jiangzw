# 零售供应链领域术语表

本文件定义本仓库所有文档的统一术语。Kiro 在生成方案、PRD、汇报材料时必须使用此处的术语。

## 一、仓储（WMS / 仓储平台化）

| 术语 | 含义 | 常见混淆点 |
|---|---|---|
| **SKU** | 最小存货单位（颜色/规格/包装唯一确定一个 SKU） | 不等于"商品"，一个商品可能对应多个 SKU |
| **库位（Location）** | 仓库内最小存储位置，含库区、巷道、货架、层、位 | 不等于"货位"或"仓位" |
| **入库（Inbound）** | 收货 → 质检 → 上架 全流程 | |
| **出库（Outbound）** | 拣选 → 复核 → 打包 → 发运 全流程 | |
| **波次（Wave）** | 一组订单按规则合并后下发拣货的批次 | |
| **拣选（Picking）** | 摘果式 / 播种式 / RF 拣选 / PTL 拣选 | |
| **复核（Checking）** | 出库前的质量与数量校验 | |
| **盘点（Stocktaking）** | 动碰盘 / 静态盘 / 循环盘 / 全盘 | |
| **越库（Cross-docking）** | 收货后不上架直接出库 | |
| **三方仓 / 自营仓** | 3PL 仓 vs 自有仓 | |
| **平台化** | 多业务线共用一套仓储能力，含租户隔离、计费分摊、SOP 配置化 | 不等于"中台" |

## 二、ERP / 主数据 / 财务

| 术语 | 含义 |
|---|---|
| **主数据** | 商品、供应商、客户、组织、库位等基础数据 |
| **商品档案** | 商品主数据，含基础属性、包装规格、关务信息、税率 |
| **采购订单（PO）** | 向供应商下单凭证 |
| **销售订单（SO）** | 接收客户订单的凭证 |
| **调拨单（TO）** | 仓间或组织间库存转移 |
| **应付（AP）/ 应收（AR）** | 财务挂账与对账 |
| **对账单** | 与供应商/客户/3PL 仓的账目核对 |
| **结算** | 完成对账后的付款/收款执行 |

## 三、核心业务指标（汇报必用）

| 指标 | 单位 | 业务含义 |
|---|---|---|
| **库存周转天数** | 天 | 平均库存 ÷ 日均销售成本，越低越好 |
| **缺货率（OOS）** | % | 缺货 SKU 数 ÷ 在售 SKU 数 |
| **现货率** | % | 1 - 缺货率 |
| **订单履约时效** | 小时 | 下单到出库时长（B2C 通常要求 <24h） |
| **拣选准确率** | % | 拣对件数 ÷ 总件数，目标 ≥ 99.95% |
| **人效** | 单/人/小时 或 件/人/小时 | 衡量仓库作业效率 |
| **坪效** | 元/㎡/年 | 仓储空间产出 |
| **库容利用率** | % | 已用库位 ÷ 总库位 |
| **爆仓率** | % | 库容超 95% 的天数占比 |
| **呆滞库存占比** | % | 90 天以上未动销 SKU 库存价值占比 |

## 四、组织与角色

| 角色 | 关注点 |
|---|---|
| **业务方 / 业务负责人** | 成本、效率、KPI 是否达成 |
| **仓库现场（操作 / 班长 / 主管）** | 操作便捷性、SOP 是否好执行 |
| **运营 / 计划** | 库存健康度、调拨决策 |
| **财务** | 对账准确性、结算时效 |
| **IT / 产品** | 系统稳定性、扩展性 |

## 五、撰写禁忌词（业务汇报中避免直接使用，需翻译）

| 技术词 | 业务翻译 |
|---|---|
| 微服务 / 中台 | "把通用能力沉淀下来，多业务复用" |
| API / 接口 | "系统间打通"、"数据互联" |
| SaaS / 多租户 | "一套系统支持多个业务/客户" |
| 数据库迁移 | "底层数据搬家" |
| 容灾 / 高可用 | "系统稳定不宕机" |
| 异步 / 消息队列 | "削峰填谷"、"避免拥堵" |

> **原则**：技术词只在面向 IT / 技术评审时使用；业务汇报一律翻译成业务语言。
