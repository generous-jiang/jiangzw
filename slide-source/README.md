# 武汉 FC 仓 · 海柔自动化系统方案 — 单页 PPTX 源文件

本目录生成 `../武汉FC仓海柔自动化系统方案.pptx`（16:9 宽屏，单页）。
**全部元素均为 PowerPoint 原生可编辑对象（形状 / 文本框 / 连线 / 项目符号），无任何图片。**

本页是「全渠道仓库自动化总体框架」在武汉 FC 仓的**一次落地**，主线
**FC WMS → 自研 WCS → 海柔 HAIQ 系统**，自上而下三大块：

1. **① 业务系统层 · FC WMS**（简洁）：FC Flux WMS / WHC 自动化任务编排 / 业务数据。
2. **② WCS · 仓储自动化统一调度引擎（重点·详细）**：①统一调度层 ②标准指令集（本仓启用）
   ③设备能力适配层；其中"料箱到人适配（Shuttle 类）→ 闪攀"为本仓启用能力，红色高亮。
   FC WMS 与海柔系统不直连，统一经 WCS 标准指令集下发 / 回传。
3. **③ 执行系统层 · 海柔 HAIQ 系统**（按最初的架构图分层，**非左中右三栏**）：
   - 软件系统层：WES 仓库执行系统（核心）/ ESS 设备调度系统 / DP 数据平台 + 业务功能模块（基础资料·入库·出库·库内·系统管理）
   - ↓ ESS 任务下发 / 设备状态回传
   - 物理层：设备资源层（A71-L-E1-H-CN ×150、HRC ×25、德玛输送线、安全门）｜ 工作站层（In_01~06、取箱口 ×5、out_01~22、打包台 30、异常口 101/102）

> 配套文件 `../全渠道仓库自动化接入WCS产品方案.pptx` 为「总体框架」总览页，与本落地页成对使用。

## 文件说明

| 文件 | 作用 |
|------|------|
| `slide.js`   | 唯一数据源：调色板、字体、画布尺寸与全部版面元素（与渲染器无关的 op 列表） |
| `build.js`   | 由 `slide.js` 生成 `.pptx`（pptxgenjs，原生形状 / 文本框 / 连线 / 项目符号） |
| `preview.js` | 由同一份 `slide.js` 生成 SVG→PNG 预览，坐标与 PPTX 完全一致，用于版面校对 |
| `preview.png`| 版面预览图 |

## 重新生成

```bash
npm install -g pptxgenjs sharp
export NODE_PATH=$(npm root -g)

node build.js                                   # 生成 .pptx
python /path/to/pptx/scripts/rezip.py 武汉FC仓海柔自动化系统方案.pptx   # 压缩瘦身
node preview.js                                 # 生成 preview.png（核对版面）
node preview.js debug                           # 额外输出文本框边界，用于排查溢出
```
