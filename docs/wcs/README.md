## 导入飞书的两种方式

**方式一（推荐，保留图片与排版）**
飞书云文档 → 新建 →「导入文档」→ 上传 `WCS子PRD_台州海柔飞箱项目.docx`。
图片、表格、目录会一并带入。

**方式二（纯文本，图示为表格）**
打开 `WCS子PRD_台州海柔飞箱项目_飞书版.md`，全选内容粘贴进飞书文档。
飞书会自动识别标题层级与表格。如需图示，再从 `images/` 手动插入到对应章节。

> 本次生成环境未接入飞书连接器，无法直接在飞书空间内创建文档，因此以可导入文件的形式交付。
