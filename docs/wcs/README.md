# 台州海柔飞箱项目 — WCS 子 PRD 交付物

主 PRD：《【项目】【P0】台州海柔飞箱项目》v1.1
本目录为其中 **WCS 模块**的子 PRD（当前 **v1.4**），用于 2026-08-12 与研发、测试同学评审。

> **系统链路口径**：本项目为 **门店 WMS → WCS → 海柔 WES** 三段式。
> **WCS 是本项目从 0 到 1 新建的系统，也是链路中唯一的中间层**——门店 WMS 只对接 WCS，海柔 WES 也只对接 WCS。
> §7 已按《台州飞箱（WCS-海柔接口）》逐字段核对；该接口文档需按 §7.7-R13 同步更新中间层称谓。

## 导入飞书的两种方式

**方式一（推荐，保留图片与排版）**
飞书云文档 → 新建 →「导入文档」→ 上传 `WCS子PRD_台州海柔飞箱项目.docx`。
6 张图、表格、目录会一并带入。

**方式二（纯文本，图示另有等价表格兜底）**
打开 `WCS子PRD_台州海柔飞箱项目_飞书版.md`，全选内容粘贴进飞书文档。
飞书会自动识别标题层级与表格；图片链接不会自动解析，需从 `images/` 手动插入到对应位置，
但每张图下方都附了等价表格，不插图也不影响评审阅读。

> 本次生成环境未接入飞书连接器，无法直接在飞书空间内创建文档，因此以可导入文件的形式交付。

## 评审前需要先看的四处

- **§7.7 接口清单核对发现的问题（12 项）** — 逐字段核对海柔接口清单后整理，R1～R4 属阻塞开发项，需评审会上分派给海柔 / WMS / WCS 三方。
- **§7.1 三条必须修正的设计（M1～M3）** — 移出任务无独立接口（复用出库单 + `outbound_order_type=MOVE`）、海柔无独立异步受理回执（同步响应驱动状态机）、容器信息随结果回传而非独立接口。
- **§4 标准指令模型（已定稿）** — 重点看 **§4.5 三厂商建模推演**（海柔闪拣 / 立镖飞箱 / 原力聚合四向车），三场景表结构零变更；推演暴露并修正了载具泛化与单位字段，这两列**必须在 1 期就位**。
- **§9 运维后台 + 人工兜底 SOP** — 1 期不做系统级超时告警，改人工兜底，后台的查询与人工重推是 1 期 P0。
